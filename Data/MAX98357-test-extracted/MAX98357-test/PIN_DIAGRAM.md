## 詳細接線表

| ESP32-S3 引腳 | 功能 | → | MAX98357A 引腳 | 說明 |
|--------------|------|---|----------------|------|
| **5V** | 電源 | → | **Vin** | ⚠️ 必須 5V，不可用 3.3V |
| **GND** | 接地 | → | **GND** | 共地很重要 |
| **GPIO 4** | I2S 位元時鐘 | → | **BCLK** | Bit Clock |
| **GPIO 5** | I2S 字時鐘 | → | **LRC (WS)** | Left/Right Clock |
| **GPIO 6** | I2S 數據 | → | **DIN** | Data Input |
| **GPIO 7** | 放大器開關 | → | **SD** | Shutdown (可選) |
| - | - | - | **GAIN** | 接 GND = 12dB 增益 |

## 增益設定選項

MAX98357A 的 GAIN 引腳可設定音量增益：

| GAIN 接法 | 增益 | 音量 |
|----------|------|------|
| 接 GND | 12 dB | 🔊 最大聲 (建議) |
| 懸空 (不接) | 9 dB | 🔉 標準 |
| 接 Vin | 6 dB | 🔈 較小聲 |

**建議**: 將 GAIN 接到 GND 以獲得最大音量。

## SD (Shutdown) 引腳說明

| SD 接法 | 狀態 | 用途 |
|--------|------|------|
| 接 GPIO 7 | 可程式控制 | 可用程式開關放大器 (推薦) |
| 接 3.3V 或 5V | 恆開 | 放大器永遠開啟 |
| 接 GND | 恆關 | 放大器永遠關閉 (無聲) |

## 喇叭規格

- **阻抗**: 4Ω 或 8Ω
- **功率**: 3W (典型)
- **類型**: 任何標準喇叭單體

## 接線檢查清單

在上電前請確認：

- [ ] Vin 接到 5V (不是 3.3V)
- [ ] GND 已連接且共地
- [ ] GPIO 4, 5, 6 正確連接到 BCLK, LRC, DIN
- [ ] GPIO 7 連接到 SD (或 SD 接 3.3V)
- [ ] GAIN 接到 GND (獲得最大音量)
- [ ] 喇叭已連接到 MAX98357A 輸出端
- [ ] 所有連接穩固無鬆動

## 常見問題排除

### 沒有聲音
1. 檢查 SD 引腳是否為高電位 (GPIO 7 輸出 HIGH 或接 3.3V)
2. 確認 Vin 接到 5V 而非 3.3V
3. 檢查喇叭連接是否正確

### 聲音太小
1. 將 GAIN 接到 GND (12dB 增益)
2. 確認使用 5V 供電
3. 檢查程式中的 AMPLITUDE_32 設定

### 有雜訊
1. 確認使用 32-bit I2S 模式 (已在程式中設定)
2. 檢查接線是否穩固
3. 確保 GND 連接良好

## 編譯與測試

```bash
# 編譯專案
idf.py build

# 燒錄到 ESP32 (替換 COM3 為你的端口)
idf.py -p COM3 flash monitor

# 如果燒錄失敗，按住 Boot 鍵再按 Reset 鍵
```

測試程式會播放 Do-Re-Mi-Fa-Sol 音階，如果聽到清晰的音階聲，表示接線正確！
